# PD5_daus-i-robots
Aplicació educativa de robòtica i probabilitat amb curses de robots per daus, marcador de tirades, gràfics de freqüència verticals i un simulador massiu de partides (fins a 1.000).

**2 Modes de joc:** Mode Bàsic (1 dau / 6 robots) i Mode Pro (2 daus / 12 robots).

**Anàlisi de dades en temps real:** Recompte de tirades per partida, historial independent i gràfics de barres verticals amb el robot més guanyador.

**Simulador massiu:** Execució instantània de 10, 50, 100 o 1.000 partides per comprovar la Llei dels Grans Números i descobrir la impossibilitat matemàtica que el Robot 1 avanci en el mode de dos daus.

**Accessibilitat a l'aula:** Llançament amb tecla d'espai, pistes visuals contínues i funcionament 100% en navegador.
